## 🚀 Proyectos destacados

### ToDo API
API REST para la gestión de usuarios y tareas.
- Autenticación y autorización con Spring Security y JWT.
- Persistencia con PostgreSQL y Hibernate.
- Arquitectura por capas y DTOs.

### Inventory API
Proyecto backend para la gestión de inventario.
- Gestión de productos y categorías.
- Java, Spring Boot y PostgreSQL.

### EasyPokeAPI
Aplicación que consume PokéAPI y permite consultar información de Pokémon.
- Integración con APIs externas.
- Persistencia de información en PostgreSQL.
- Backend con Spring Boot.
- Interfaz con HTML, CSS y JavaScript.
